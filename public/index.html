Every cost tool hides those hours. This one draws them.

Databricks billing reports on a lag, so a window that ends at now is part empty by construction. FinOpsWay is a free browser extension that puts one number in your workspace navigation, scoped to the page you are on, and ends its window where the data actually ends. The missing hours are hatched, never padded with silence.

$18.70 of $587 today → 11:00

The two-hour lag above is an illustration; the real figure is your workspace's own. What never changes is the rule: the window ends at the last hour billing has reached, not at the current one.

What it does

Scoped to the page

On a cluster, SQL warehouse, job, job run, pipeline or pipeline update page the chip answers for that resource, with the workspace as its denominator. On the home page, the workspace alone. An unrecognised page falls back to workspace scope rather than to a blank chip.

A real query, from your browser

It runs a read-only SQL query against the system.billing tables from the browser itself. No backend, no OAuth flow, nothing to deploy. The credential is a workspace personal access token you paste into the options page, or optionally the browser session you already have.

Free, structurally

With no servers there are no costs to recover, so free is not a tier, it is architecture. No account, no trial, no telemetry, nothing to sell. The toolbar's own price tag is the one thing in your workspace that reads $0.

Where it runs

Clouds
Databricks on AWS (*.cloud.databricks.com) and Azure (*.azuredatabricks.net). Everything above the hostname is identical on both.
Browsers
Chrome, Edge and Firefox, as a Manifest V3 extension.
Credential
A workspace personal access token, pasted into the extension's own options page. It never leaves the browser.

Your data

The extension has no backend and no telemetry. Nothing it reads leaves your browser except the query itself, which goes to the Databricks workspace you are already signed in to. We operate no server, receive no data, and have no way to see what you query.

Data the extension handles is used only to display your Databricks spend, which is its single purpose. None of it is sold, transferred to third parties, or used for advertising. Read the full privacy policy.
