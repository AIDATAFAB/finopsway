What it does Where it runs

Today's Databricks cost, on the page you are already looking at.

FinOpsWay is a browser extension that puts one number in your Databricks workspace navigation: what this cluster, warehouse, job or pipeline has cost today, and what the whole workspace has cost around it.

$18.70 of $587 today → 11:00

The window ends where billing has actually reported, not at the current hour. A number that hides its own missing hours is worse than no number.

What it does

Scoped to the page

On a cluster, SQL warehouse, job, job run, pipeline or pipeline update page you get that resource's own spend against the whole workspace's, so the smaller figure always arrives with a denominator. On the home page it is the workspace alone.

An honest window

Billing reports on a lag, so a window ending at now is part empty by construction. The chip ends its window where the data actually stops and draws the hours since as a hatched overhang.

No backend

It runs a real SQL query against the system.billing tables from the browser itself. No service to deploy, no OAuth flow. The credential is a workspace personal access token you paste into the options page.

Where it runs

Clouds
Databricks on AWS (*.cloud.databricks.com) and Azure (*.azuredatabricks.net). Everything above the hostname is identical on both.
Browsers
Chrome, Edge and Firefox, as a Manifest V3 extension.
Credential
A workspace personal access token, pasted into the extension's own options page. It never leaves the browser.

Availability

FinOpsWay is in active development and is not publicly available yet. There is nothing to download: it has not been submitted to the Chrome, Edge or Firefox extension stores.

Install instructions will land on this page when it is ready to hand out.
